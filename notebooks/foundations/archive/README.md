# Foundations Archive

This archive preserves the complete set of migrated mathematical, machine
learning, reinforcement learning, FeatureGraph-origin, and EventQL records.

The files have not been silently corrected. Saved notebook outputs, incomplete
experiments, old dependency usage, and known mistakes remain part of the
historical record. Nothing inside `source_records/` is part of FeatureGraph's
stable API.

Use [`INVENTORY.csv`](INVENTORY.csv) to identify which ideas were promoted,
which files remain supporting references, and which artifacts should only be
consulted as history.

The active material is one level above in
[`../curated/`](../curated/README.md).
